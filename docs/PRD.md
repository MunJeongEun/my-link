# 1. 제품 개요

## 1.1 서비스명

**마이링크(MY LINK)**

## 1.2 서비스 한 줄 소개

개인 크리에이터와 일반 사용자가 자신의 SNS와 다양한 URL을 하나의 프로필 페이지에 모아 공유할 수 있는 멀티 링크 & 바이오 프로필 서비스

## 1.3 개발 목적

인스타그램, 유튜브 등 여러 플랫폼의 링크를 하나의 페이지에서 보여줄 수 있도록 하여 사용자가 자신의 온라인 활동과 콘텐츠를 간편하게 공유할 수 있도록 한다.

본 프로젝트는 수업/과제용 프로토타입을 목적으로 하며, 실제 서버나 회원 인증 없이 **Mock 데이터와 LocalStorage를 활용한 클라이언트 전용 데모**로 구현한다. 디자인 및 컴포넌트 아키텍처는 **shadcn/ui**를 기반으로 하되, **design.md의 토스 디자인 시스템(TDS)**을 반영한 비주얼 언어(단일 강조색 정책, 공격적 라운드, List-Row 패턴, 해요체 보이스)를 적용하여 구축한다.

# 2. 목표 사용자

## 2.1 핵심 사용자

* 개인 크리에이터
* 일반 SNS 사용자

## 2.2 사용자 니즈

* 여러 SNS와 웹사이트 링크를 한곳에서 관리하고 싶다.
* SNS 프로필에 하나의 URL만 등록하고 여러 링크를 보여주고 싶다.
* 자신의 이름, 사진, 소개 등을 활용해 간단한 바이오 페이지를 만들고 싶다.
* 복잡한 설정 없이 링크를 추가하고 순서를 변경하고 싶다.

# 6. 상태 관리

프로젝트의 전역 상태 관리는 **Zustand**를 사용한다.

## 관리 대상

* 프로필 정보
* 소셜 미디어 목록
* 링크 목록
* 섹션 헤더 목록
* 선택한 테마

## 역할

Zustand를 사용하여 편집 화면과 공개 프로필 화면에서 필요한 데이터를 일관되게 공유하고 관리한다.

사용자가 편집 화면에서 데이터를 변경하면 Zustand의 전역 상태에 반영하고, 저장 시 해당 상태를 LocalStorage에 저장한다.

LocalStorage에 저장된 데이터는 애플리케이션 실행 시 Zustand 상태로 불러와 초기화한다.

### 데이터 흐름

**LocalStorage → Zustand 전역 상태 → 각 UI 컴포넌트**

사용자의 수정 과정에서는:

**사용자 입력 → Zustand 상태 변경 → UI 반영 → 저장 → LocalStorage**

와 같은 흐름으로 동작하도록 구현한다.

# 9. 디자인 시스템 및 UI 컴포넌트

모든 화면과 인터랙션의 UI 컴포넌트는 **shadcn/ui** 아키텍처를 기반으로 구축하되, 시각적 스타일과 인터랙션은 **design.md의 토스 디자인 시스템(TDS)**을 적용하여 설계한다.

## 9.1 핵심 원칙

* **스타일링 방식 (Tailwind CSS 100% 통일)**:
  * 별도의 **CSS Modules(모듈 CSS, *.module.css)는 전면 배제**하며, 컴포넌트 및 페이지의 모든 스타일은 **Tailwind CSS v4 유틸리티 클래스**로 일원화한다.
  * `globals.css`의 CSS 변수(`--tds-*` 및 `--primary`, `--background`, `--card`, `--radius` 등)와 `@theme inline`을 통해 TDS 토큰과 shadcn/ui 테마를 완벽히 일치시킨다.
  * 스타일 확장이 필요할 경우 shadcn/ui의 `cn` 유틸리티(`clsx` + `tw-merge`)를 통해 안전하게 클래스를 결합한다.
* **shadcn/ui 컴포넌트 아키텍처**: Button, Input, Dialog, Card, Avatar, Badge, Dropdown Menu 등 모든 UI 요소는 shadcn/ui의 접근성(WAI-ARIA)과 컴포넌트 프리미티브를 기반으로 구현한다.
* **토스 디자인 시스템(TDS) 룩앤필 적용**:
  * **단일 강조색 정책**: 화면당 단 하나의 가장 중요한 액션에만 카노니컬 토스 블루(`blue-500`: `#3182F6`)를 적용하고, 보조 액션은 중성 표면(`grey-100`) 또는 고스트 스타일로 분리한다.
  * **절제된 중성 캔버스**: 화이트 표면과 쿨톤 그레이스케일(`grey-50`~`grey-900`), 1px 헤어라인 디바이더(`grey-200`)로 깨끗하고 신뢰감 있는 레이아웃을 유지한다.
  * **공격적이고 정갈한 라운드**: 버튼(XL 16px, L 14px), 카드/컨테이너(16~24px), 칩/배지(full pill 999px) 등 TDS 라운드 래더(ladder)를 엄격히 준수한다.
  * **List-Row 및 모바일 셸 패턴**: 모바일 환경(최대 너비 430px 단일 컬럼)을 1차 기준으로 삼고, 콘텐츠 행은 둥근 아이콘 슬롯과 타이틀/서브텍스트 스택, 우측 Chevron으로 구성된 TDS List-Row 패턴을 적용한다.
  * **해요체(대화형 존댓말) 보이스**: 프로필 및 시스템 카피는 토스의 커뮤니케이션 원칙에 따라 대화형 존댓말(해요체)과 친근하고 명확한 일상어로 작성한다.
* **아이콘 표준**: `lucide-react` 및 정밀 벡터 SVG(`GithubIcon`, `VelogIcon`, `LinkedinIcon` 등)를 표준으로 사용하며, `PlatformIcon` 컴포넌트를 통해 플랫폼명을 기반으로 유연하게 매핑한다.

   * 모바일 단일 컬럼 규격(최대 430px)과 상단 내비게이션 바, 하단 푸터를 감싸는 반응형 셸 래퍼 컴포넌트.
7. **`PlatformIcon` (`src/components/icons.tsx`)**:
   * 플랫폼 식별 문자열에 따라 알맞은 Lucide/SVG 아이콘을 동적으로 반환하는 재사용 아이콘 컴포넌트.

# 10. 주요 사용자 시나리오

## 시나리오 1. 프로필 생성

1. 사용자가 관리 화면에 진입한다.
2. 프로필 사진을 등록한다.
3. 이름과 소개 문구를 입력한다.
4. 저장한다.
5. 공개 프로필에 입력한 정보가 표시된다.

## 시나리오 2. SNS 추가

1. 사용자가 관리 화면에서 소셜 미디어 추가를 선택한다.
2. Instagram을 선택한다.
3. 자신의 Instagram URL을 입력한다.
4. 저장한다.
5. 공개 프로필에 Instagram 아이콘이 표시된다.
6. 아이콘을 클릭하면 새 탭에서 Instagram이 열린다.

## 시나리오 3. 링크 추가

1. 사용자가 링크 추가를 선택한다.
2. 링크 제목을 입력한다.
3. URL을 입력한다.
4. 저장한다.
5. 공개 프로필에 링크 버튼이 표시된다.
6. 사용자가 버튼을 클릭하면 새 탭에서 해당 사이트가 열린다.

## 시나리오 4. 링크 순서 변경

1. 관리 화면에서 링크 목록을 확인한다.
2. 링크의 순서를 변경한다.
3. 변경 내용을 저장한다.
4. 공개 프로필에서 변경된 순서로 링크가 표시된다.

## 시나리오 5. 테마 변경

1. 관리 화면에서 테마 설정을 선택한다.
2. 원하는 테마를 선택한다.
3. 저장한다.
4. 공개 프로필에 선택한 테마가 적용된다.

# 12. 비기능 요구사항

### 디자인 시스템 & UI 일관성

* 향후 모든 컴포넌트 및 인터페이스 개발은 **shadcn/ui** 컴포넌트를 기반으로 진행하되, 룩앤필은 **design.md의 토스 디자인 시스템(TDS)**을 따른다.
* **TDS 핵심 디자인 언어 준수**:
  - 단일 액션 강조(Toss Blue `#3182F6`)와 절제된 쿨 그레이스케일(`grey-50`~`grey-900`)
  - 공격적인 라운드 모서리(버튼 14~16px, 카드/모달 16~24px, 칩/배지 999px full pill)
  - 1px 헤어라인 디바이더(`grey-200`) 및 List-Row 형태의 목록 컨테이너
  - 한글 가독성을 최적화한 Pretendard 타이포그래피와 해요체(대화형 존댓말) 보이스
* 디자인 시스템은 별도의 CSS Modules(모듈 CSS) 없이 Tailwind CSS v4의 테마 토큰 및 CSS 변수를 활용하여 100% 일관성 있는 스타일 규칙을 유지한다.
* 웹 표준 및 웹 접근성(WAI-ARIA)을 준수하는 shadcn/ui 컴포넌트 기본 스펙을 적극 활용한다.
* 컴포넌트는 단일 책임과 높은 재사용성을 가지도록 분리(ListRow, SectionHeader, LinkList, ProfileHeader, SocialBar 등)하여 관리한다.

### 사용성

* 사용자가 별도의 설명 없이 기본적인 링크 추가/수정을 수행할 수 있어야 한다.
* 편집 화면과 공개 프로필 화면을 명확하게 구분한다.

### 반응형

* 모바일과 PC 화면에서 주요 기능과 콘텐츠가 정상적으로 표시되어야 한다.

### 데이터 유지

* LocalStorage에 저장된 데이터는 페이지 새로고침 후에도 유지되어야 한다.
* 애플리케이션 실행 시 LocalStorage 데이터를 Zustand 상태로 불러와야 한다.

### 상태 관리

* 주요 애플리케이션 데이터는 Zustand를 통해 관리한다.
* 컴포넌트 간 동일한 데이터를 일관되게 사용할 수 있어야 한다.

### 외부 링크

* 등록된 외부 링크는 새 탭에서 열려야 한다.

# 13. 성공 기준

수업/과제용 프로토타입이므로 실제 사용자 수나 매출 등의 지표보다는 **핵심 기능의 정상 작동 여부**를 기준으로 한다.

* 프로필 정보를 저장하고 공개 페이지에서 확인할 수 있다.
* SNS 아이콘을 추가하고 외부 페이지로 이동할 수 있다.
* URL 링크를 추가·수정·삭제할 수 있다.
* 링크 순서를 변경할 수 있다.
* 섹션 헤더로 링크 영역을 구분할 수 있다.
* 테마를 변경할 수 있다.
* shadcn/ui 컴포넌트를 기반으로 UI가 정합성 있게 렌더링된다.
* 새로고침 후에도 저장된 데이터가 유지된다.
* PC와 모바일에서 페이지가 정상적으로 표시된다.
* 편집 화면과 공개 페이지가 동일한 전역 상태 데이터를 기반으로 정상적으로 표시된다.

# 14. 프로젝트 핵심 가치

마이링크는 여러 온라인 활동을 하나의 URL로 연결하여 개인의 SNS와 콘텐츠를 간편하게 소개할 수 있도록 하는 서비스다.

이번 프로젝트에서는 실제 서비스의 복잡한 인증이나 백엔드보다는 **프로필 생성 → 콘텐츠 구성 → 공개 페이지 확인**이라는 핵심 사용자 경험을 구현하는 데 초점을 둔다.

또한 **Zustand를 활용한 전역 상태 관리와 LocalStorage 기반 데이터 저장 구조**를 적용하여, 별도의 백엔드 없이도 편집 화면과 공개 프로필 간 데이터를 일관되게 관리할 수 있도록 한다.
